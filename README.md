# dynamiclayer_flutter (Free)

Free starter version of Dynamic Layer Flutter components.

## Included components

- `DlButton`
- `DlButtonIcon`
- `DlButtonDock`
- `DlBadge`
- `DlBottomNavigation`
- `DlCard`
- `DlInput`
- `DlSeparator`
- `DlTopNavigation`

## Setup

```yaml
dependencies:
  dynamiclayer_flutter:
    git:
      url: https://github.com/dynamiclayer/dynamiclayer-free.git
      ref: main
```

Then run:

```bash
flutter pub get
```

## Usage

```dart
import 'package:dynamiclayer_flutter/dynamiclayer_flutter.dart';
```

For all components and templates, upgrade to the private Pro repository.
