# Component Roadmap

## Planned order

1. Button
2. Input/TextField
3. Card
4. Badge
5. Modal/Dialog
6. Navigation building blocks

## Definition of done (for every component)

A component is considered complete only if all of the following are done:

1. **Implementation** in `lib/src/components/`
2. **Test** coverage in `test/components/`
3. **Documentation** file in `docs/components/`
4. **Example usage** integrated in `example/`

## Delivery notes

- Prioritize stable APIs before adding advanced variants.
- Keep components composable and themeable.
- Avoid shipping app-specific behavior in the component library.
